# Pick-Up-And-Give

Pick-Up-And-Give is a platform built together with Let's Save Food to manage food donations, pickups, deliveries, and distribution-center operations.

The app coordinates **providers** (restaurants, stores), **volunteers** (delivery drivers), and **administrators** in a unified workflow to reduce food waste and ensure timely delivery of donations.

There's also a fully build in websocket chatroom with different channels. we provided 3 different types of channels
- Community channels: big generalised groups of user types for general operations or social chatrooms
- Distribution channels: channels related to one single distribution center for operational messages
- Supplier channels: each provider gets a dedicated chatroom for order related chats

## Project Structure

This is an npm monorepo with three packages:

- **`backend`** – Express API, authentication, routing logic
- **`frontend`** – Next.js web application
- **`shared`** – Zod schemas and TypeScript types

## Setup

### 1) Prerequisites

- Node.js 20+
- npm 10+
- PostgreSQL database (local or hosted)

### 2) Install dependencies

Run from the repository root:

```bash
npm install
```

### 3) Configure environment variables

Create these env files:

- `backend/.env`
- `frontend/.env.local`

Suggested local values:

`backend/.env`

```env
DATABASE_URL=postgres connection string
FRONTEND_URL=http://localhost:3000
SESSION_SECRET=replace-with-a-long-random-string
PORT=5000
```

`frontend/.env.local`

```env
NEXT_PUBLIC_API_BASE_URL=http://localhost:5000/api
```

### 4) Initialize database

NOTE: <br /> you can also go to the right folder and run the same commands without -w backend/frontend

From the root:


```bash
npm run -w backend db:migrate
npm run -w backend db:seed
```

Or reset and reseed everything:

```bash
npm run -w backend db:reset-seed
```

### 5) Start the app

Run frontend and backend together (from root):

```bash
npm run dev
```

- Frontend: http://localhost:3000
- Backend API: http://localhost:5000/api

## Commands

### Root commands

- `npm run dev` - start all workspace dev scripts
- `npm run build:all` - build all workspaces

### Backend commands

- `npm run -w backend dev` - start backend in development mode
- `npm run -w backend build` - compile backend TypeScript
- `npm run -w backend start` - run compiled backend build
- `npm run -w backend test` - run backend tests once (Vitest)
- `npm run -w backend test:watch` - run backend tests in watch mode
- `npm run -w backend db:generate` - generate Drizzle migration files
- `npm run -w backend db:migrate` - apply migrations
- `npm run -w backend db:studio` - open Drizzle Studio
- `npm run -w backend db:seed` - seed database data
- `npm run -w backend db:drop` - drop all database objects (dev utility)
- `npm run -w backend db:reset-seed` - drop, migrate, and reseed

### Frontend commands

- `npm run -w frontend dev` - start Next.js dev server
- `npm run -w frontend build` - build frontend
- `npm run -w frontend start` - start production frontend
- `npm run -w frontend lint` - run ESLint

## Tests

Current automated tests are in the backend package and run with Vitest.

- Run once:

```bash
npm run -w backend test
```

- Watch mode:

```bash
npm run -w backend test:watch
```

Current tests covers:

- create order
- auto-assign center
- claim delivery
- send completion message
- complete delivery
