### Key Backend Folders

- **`src/config`**: Database and authentication configuration
- **`src/db`**: ORM schema, migrations, and database utilities
- **`src/middleware`**: Authentication and authorization guards
- **`src/routes`**: Feature-based API endpoint modules
- **`src/services`**: Reusable business logic utilities
- **`drizzle/migrations`**: SQL migration files (auto-generated by Drizzle)
- **`uploads`**: Persisted user uploads (images)

## How to Navigate the Codebase Quickly

1. **For an API behavior change**: Start in `backend/src/routes`, then check `backend/src/middleware`, then `shared/schemas`.
2. **For a page or UI behavior change**: Start in `frontend/src/app`, then related `frontend/src/components`, then `frontend/src/lib`.
3. **For payload or type mismatches**: Inspect `shared/schemas` first — this is the source of truth.
4. **For authentication issues**: Check `backend/src/config/passport.ts` and `frontend/src/lib/auth-context.tsx`.
5. **For chat features**: See `backend/src/routes/chatRoutes.ts` and `frontend/src/components/chatroom/`.
